# 要確認ポイント

本書では仮の決定で書いている項目です。決まったら該当ファイルを更新し、ここから消して変更履歴に残します。

| ID | 確認したいこと | 本書での仮の決定 | 他の選択肢 |
|---|---|---|---|
| Q-01 | 課題の提出期限・発表日 | 8週間のスケジュール案([07](07-schedule-deliverables.md)) | 期限に合わせて Should / Could を削る |
| Q-02 | 完成写真を v1 に入れるか | 入れる(Should、F-09)。ローカルは RustFS、本番は S3 など | 入れない(画像ストレージが不要になり、環境構築とデプロイが簡単になる) |
| Q-03 | ゲスト(未ログイン)の閲覧 | 一覧・詳細・検索はゲストも見られる | 閲覧もログイン必須にする |
| Q-04 | カテゴリの種類 | 主菜 / 副菜 / 汁物 / 主食 / デザート / その他 の固定6種類 | 種類を増やす / 自由タグにする |
| Q-05 | DB アクセスの方式 | Spring Data JPA(trello-clone と同じ) | MyBatis(sns-timeline-app と同じ) |
| Q-06 | デモ環境のデプロイ先 | 未定 | Render の無料枠(画像ストレージは別途必要) / AWS(ECS・RDS・S3 等。費用がかかる) |
| Q-07 | スクールから指定された必須要件(使用技術・必須機能・提出形式など)の有無 | 指定なしとして作成 | 指定があれば本書に反映する |
