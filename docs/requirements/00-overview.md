# 概要・対象ユーザー・用語定義

## 1. 背景・目的

### 1.1 背景
- スクール課題として、Webアプリケーションを要件定義から実装・デプロイまで一通り作る。
- 家庭の定番料理や工夫したレシピは、本人のメモや頭の中にしかないことが多い。気軽に書き残して他の人と共有でき、作りたい料理をすぐ探せる場所があると便利。

### 1.2 目的
- 誰でもレシピ(材料・手順・写真)を投稿し、誰でも閲覧・検索できるようにする。
- 気に入ったレシピをお気に入りに保存し、あとで作るときにすぐ開けるようにする。
- 学習面では、認証・認可(本人だけが編集できる)、親子関係のあるデータ(レシピと材料・手順)の登録・更新、検索・絞り込み、画像アップロード、REST API とフロントエンドの連携を一通り実装する。

### 1.3 コンセプト
| 観点 | 方針 |
|---|---|
| 公開範囲 | 投稿したレシピは全体公開。ログインしていなくても閲覧・検索できる |
| 投稿 | ログインしたユーザーなら何件でも投稿できる |
| 探しやすさ | キーワード(料理名・材料名)、カテゴリ、調理時間で絞り込める |
| 再利用 | お気に入りに保存して、自分専用のレシピ帳として使える |

## 2. 対象ユーザー
| ユーザー像 | 利用シーン |
|---|---|
| 料理をする人(初心者〜家庭料理に慣れた人) | 冷蔵庫にある材料や作りたい料理名で検索し、レシピを見ながら作る |
| 自分のレシピを残したい・広めたい人 | 定番料理や工夫したレシピを写真付きで投稿する |
| 献立に悩む人 | 新着・人気のレシピを眺めて、気になったものをお気に入りに保存する |

- 想定規模(課題の範囲): ユーザー 100人程度、レシピ 1,000件程度。

## 3. 用語定義
| 用語 | 意味 |
|---|---|
| ユーザー | アカウント登録してログインした利用者 |
| ゲスト | ログインしていない利用者。閲覧・検索だけできる |
| レシピ | 料理名・説明・完成写真・分量(何人分)・調理時間・カテゴリ・材料・手順をまとめたもの |
| 投稿者 | レシピを投稿したユーザー。そのレシピを編集・削除できる唯一のユーザー |
| 材料 | レシピに使う食材と分量(例: 「玉ねぎ」「1個」)。表示順を持つ |
| 手順 | 作り方の1ステップ。番号順に並ぶ |
| カテゴリ | レシピの分類(主菜 / 副菜 / 汁物 / 主食 / デザート / その他)。1レシピに1つ |
| お気に入り | ユーザーが後で見るために保存したレシピ。保存数は人気順の並び替えに使う |
| コメント | レシピに付ける感想・質問などの短い文章 |
