# 機能要件・受け入れ基準

優先度: **Must** = v1 で必ず実装 / **Should** = v1 で可能なら実装 / **Could** = 余裕があれば(未実装でも v1 は完成とする)

## 4. 機能一覧

| ID | 機能 | 概要 | ログイン | 優先度 |
|---|---|---|---|---|
| F-01 | ユーザー登録 | ユーザー名・表示名・メールアドレス・パスワードで登録する | 不要 | Must |
| F-02 | ログイン / ログアウト | メールアドレスとパスワードでログインする | 不要 | Must |
| F-03 | レシピ投稿 | 料理名・説明・分量・調理時間・カテゴリ・材料・手順を入力して投稿する | 必要 | Must |
| F-04 | レシピ編集・削除 | 自分のレシピを編集・削除する | 必要 | Must |
| F-05 | レシピ一覧 | レシピを新着順で一覧表示する | 不要 | Must |
| F-06 | レシピ詳細 | 1件のレシピの全情報を表示する | 不要 | Must |
| F-07 | 検索・絞り込み | キーワード・カテゴリ・調理時間で絞り込む | 不要 | Must |
| F-08 | お気に入り | レシピをお気に入りに保存 / 解除し、一覧で見る | 必要 | Must |
| F-09 | 完成写真 | レシピに完成写真を1枚付ける | 必要 | Should |
| F-10 | 人気順の並び替え | 一覧・検索結果をお気に入り数の多い順に並べる | 不要 | Should |

## 5. 機能詳細・受け入れ基準

### F-01 ユーザー登録
- 入力項目: ユーザー名(半角英数字と `_`、3〜20文字、一意)、表示名(1〜20文字)、メールアドレス(一意)、パスワード(8〜72文字)
- 受け入れ基準
  - [ ] 正しい入力で登録すると、そのままログイン状態になりトップ画面へ移動する
  - [ ] ユーザー名・メールアドレスが既に使われている場合、項目ごとにエラーを表示して登録しない
  - [ ] パスワードはハッシュ化して保存し、平文ではどこにも保存・出力しない

### F-02 ログイン / ログアウト
- 受け入れ基準
  - [ ] 正しいメールアドレスとパスワードでログインできる
  - [ ] 誤っている場合は「メールアドレスまたはパスワードが違います」とだけ表示する(どちらが違うかは教えない)
  - [ ] ログアウトしても、レシピの閲覧・検索はそのまま続けられる
  - [ ] ゲストがログインの必要な操作(投稿・お気に入り・コメント)をしようとしたらログイン画面へ移動し、ログイン後は元の画面に戻る

### F-03 レシピ投稿
- 入力項目
  | 項目 | 必須 | 制約 |
  |---|---|---|
  | 料理名 | ○ | 1〜50文字 |
  | 説明(ひとこと) | | 0〜300文字 |
  | 分量 | ○ | 1〜20人分(整数) |
  | 調理時間 | ○ | 1〜600分(整数) |
  | カテゴリ | ○ | 主菜 / 副菜 / 汁物 / 主食 / デザート / その他 から1つ |
  | 材料 | ○ | 1〜50行。各行は 材料名(1〜30文字)と分量(0〜20文字、例: 「大さじ1」「少々」) |
  | 手順 | ○ | 1〜30ステップ。各ステップは 1〜300文字 |
  | 完成写真 | | F-09 参照 |
- 受け入れ基準
  - [ ] 材料・手順は行を追加・削除・並び替えでき、入力した順で保存される
  - [ ] 入力エラーがある場合は項目ごとにメッセージを表示し、入力内容を消さない
  - [ ] 投稿すると、そのレシピの詳細画面へ移動する
  - [ ] レシピと材料・手順は1回の操作でまとめて保存し、途中で失敗した場合はどれも保存しない

### F-04 レシピ編集・削除
- 受け入れ基準
  - [ ] 投稿者は自分のレシピのすべての項目を編集できる。材料・手順の追加・削除・並び替えも反映される
  - [ ] 投稿者は自分のレシピを削除できる。削除前に確認ダイアログを出す。削除するとお気に入り・コメント・写真も消える
  - [ ] 他人のレシピには編集・削除ボタンを表示せず、API を直接呼んでも拒否する(403)
  - [ ] 編集したレシピには最終更新日を表示する

### F-05 レシピ一覧
- 受け入れ基準
  - [ ] トップ画面にレシピを新着順でカード表示する。各カードに完成写真(なければ代わりの画像)・料理名・投稿者の表示名・調理時間・お気に入り数を表示する
  - [ ] 1回に 20件表示し、「もっと見る」で続きを読み込む

### F-06 レシピ詳細
- 受け入れ基準
  - [ ] 料理名・完成写真・説明・投稿者・分量・調理時間・カテゴリ・材料一覧・手順(番号付き)・お気に入り数・投稿日 / 更新日を表示する
  - [ ] 存在しない・削除済みのレシピは「レシピが見つかりません」と表示する(API は 404)

### F-07 検索・絞り込み
- 条件(組み合わせ可、すべて AND)
  - キーワード: 料理名または材料名に含まれる(部分一致、英字の大文字・小文字は区別しない)。スペース区切りで複数指定すると、すべてを含むものに絞る
  - カテゴリ: 1つ選ぶ(未選択はすべて)
  - 調理時間: 「15分以内」「30分以内」「60分以内」「指定なし」から選ぶ
- 受け入れ基準
  - [ ] 条件に合うレシピだけが一覧と同じ表示で出る。該当がなければ「条件に合うレシピがありません」と表示する
  - [ ] 検索条件は URL のクエリに反映し、再読み込み・共有しても同じ結果になる
  - [ ] 例: キーワード「卵 玉ねぎ」で、料理名か材料に卵と玉ねぎの両方を含むレシピが出る

### F-08 お気に入り
- 受け入れ基準
  - [ ] レシピ詳細・一覧のボタンでお気に入りに保存 / 解除できる。同じレシピを二重に保存することはない
  - [ ] 自分のレシピもお気に入りにできる
  - [ ] お気に入り一覧画面で、保存したレシピを保存した日の新しい順に表示する
  - [ ] お気に入り一覧は本人だけが見られる(誰が何を保存したかは他人に見せない。見せるのは件数だけ)

### F-09 完成写真
- 受け入れ基準
  - [ ] レシピの投稿・編集時に、JPEG / PNG / WebP、5MB 以下の画像を1枚付けられる。差し替え・削除もできる
  - [ ] 形式・サイズが条件外の場合はエラーを表示し、保存しない(拡張子だけでなくファイルの中身で形式を確認する)
  - [ ] 写真がないレシピには代わりの画像を表示する

### F-10 人気順の並び替え
- 受け入れ基準
  - [ ] 一覧・検索結果を「新着順」「人気順(お気に入り数の多い順、同数なら新しい順)」で切り替えられる

### F-11 コメント
- 入力項目: 本文(1〜300文字)
- 受け入れ基準
  - [ ] ログインしたユーザーはレシピにコメントを書ける。ゲストも閲覧はできる
  - [ ] 古い順に表示する
  - [ ] 自分のコメントは削除できる。レシピの投稿者は自分のレシピについたコメントを削除できる

### F-12 ユーザーページ
- 受け入れ基準
  - [ ] 表示名・ユーザー名・自己紹介と、そのユーザーが投稿したレシピを新着順で表示する
  - [ ] 一覧・詳細の投稿者名からユーザーページへ移動できる

### F-13 プロフィール編集
- 入力項目: 表示名(1〜20文字)、自己紹介(0〜200文字)
- 受け入れ基準
  - [ ] 変更内容がレシピ一覧・詳細・ユーザーページの表示名に反映される
  - [ ] ユーザー名・メールアドレスの変更は v1 では対象外

### F-14 分量の換算
- 受け入れ基準
  - [ ] レシピ詳細で人数を変えると、材料の分量のうち先頭の数値(例: 「200g」「大さじ2」「1/2個」)を比例して表示し直す
  - [ ] 数値を含まない分量(「少々」「適量」)はそのまま表示する
  - [ ] 表示を変えるだけで、保存されたレシピは変わらない
