# スコープ外・拡張ロードマップ

## 12. スコープ外(v1 では作らない)
| 機能 | 理由 |
|---|---|
| 手順ごとの写真、複数枚の写真、動画 | v1 は完成写真1枚に絞る |
| 非公開・下書きのレシピ | v1 は投稿したら即公開とする。要望があれば v2 で検討 |
| 自由タグ(ハッシュタグ) | v1 は固定カテゴリのみ |
| フォロー・フォロワー、通知 | v2 以降 |
| 「作ってみた」報告(写真付きの感想) | v2 以降。v1 はコメントで代用する |
| 評価(星の数) | お気に入り数で人気を表す |
| 栄養・カロリー計算、献立作成、買い物リスト | 課題の範囲を超えるため作らない |
| パスワードリセット・メールアドレス確認 | メール送信基盤が必要なため v2 以降 |
| ユーザー名・メールアドレスの変更、退会 | v2 以降 |
| 通報・管理者画面 | v2 以降(全体公開のため、本番運用するなら必要) |

## 13. 拡張ロードマップ
| バージョン | 内容 |
|---|---|
| v1 | F-01〜F-09(Must)。1週間(2026-11-08〜11-15)で作り、デモ環境(Vercel + Supabase)にデプロイする |
| v1.1 | F-10〜F-14(人気順の並び替え、ユーザーページ、コメント、プロフィール編集、分量の換算)。v1 が完成してから、時間があれば追加する |
| v2 | 下書き・非公開、自由タグ、「作ってみた」報告、フォローと通知、通報、パスワードリセット |
| v3 | 手順ごとの写真、材料からのおすすめ(冷蔵庫の材料を選ぶと作れるレシピを出す)、買い物リスト |
