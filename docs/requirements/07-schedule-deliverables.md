# スケジュール・成果物

## 14. スケジュール(案)
課題の提出期限が決まり次第、日付を入れる([要確認ポイント](09-open-questions.md) Q-01)。

| フェーズ | 内容 | 目安 |
|---|---|---|
| 1. 要件定義 | 本書の作成・レビュー | 1週目 |
| 2. 設計 | API 設計、テーブル設計(本書のデータモデルを詳細化)、画面設計 | 1〜2週目 |
| 3. 環境構築 | リポジトリ構成、docker-compose(DB・画像ストレージ)、Spring Boot / Vite の雛形、CI | 2週目 |
| 4. 実装(Must) | F-01〜F-08 | 3〜5週目 |
| 5. 実装(Should / Could) | F-09〜F-14 | 6週目 |
| 6. テスト・修正 | 受け入れ基準に沿った確認、不具合修正、サンプルレシピの投入 | 7週目 |
| 7. デプロイ・発表準備 | デモ環境の公開、README 整備、発表資料 | 8週目 |

- 機能ごとに Issue を作り、Issue → 作業ブランチ → Pull Request の流れで進める(`CLAUDE.md` 参照)。
