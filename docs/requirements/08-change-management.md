# 変更管理

## 16. 変更管理
- 本書の内容を変更するときは、該当ファイルを更新したうえで、下記の変更履歴に追記する。
- [スコープ外](06-scope-and-roadmap.md) の機能を追加したくなった場合は、先に本書を更新(Pull Request)してから実装に着手する。
- 実装中に仕様を変えた場合も、実装の Pull Request と同時に本書を更新し、実装と本書がずれないようにする。
